## Long Callouts (For Detailed Portfolio Pages)

### Full Project Description

**BloodPG - Blood Pressure & Health Tracking Platform**

A comprehensive full-stack web application designed to help users track and manage their blood pressure readings and medication schedules. Built with modern web technologies and best practices for scalability, security, and user experience.

**Key Features:**
- **User Authentication:** Secure Google OAuth integration via Supabase
- **Data Tracking:** Log blood pressure readings with AM/PM timestamps
- **Medication Management:** Track medications associated with each reading
- **Data Visualization:** Interactive charts showing trends over time using Recharts
- **PDF Generation:** Export health reports as PDFs for healthcare providers
- **Admin Dashboard:** Comprehensive admin panel for user and data management
- **Responsive Design:** Fully responsive with dark/light mode support
- **HIPAA Considerations:** Built with privacy and security best practices

**Technical Implementation:**
- **Frontend:** Next.js 16 with App Router, TypeScript, Tailwind CSS
- **Backend:** Supabase (PostgreSQL database, Row Level Security, Authentication)
- **State Management:** React Context API for authentication state
- **Data Visualization:** Recharts for trend analysis
- **PDF Generation:** jsPDF and html2pdf.js for report generation
- **Deployment:** Netlify with automated CI/CD pipeline
- **Environment Management:** Separate staging and production environments

**Development Highlights:**
- Resolved Next.js 16 Turbopack compatibility issues with Tailwind CSS
- Implemented secure environment variable management
- Created automated favicon generation system
- Set up comprehensive deployment pipeline with staging/production separation
- Optimized build process for production performance

**Live Demo:** https://bloodpg.com
**Staging:** https://bloodpg-staging.netlify.app
